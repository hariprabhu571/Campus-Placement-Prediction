# Campus Placement Prediction - Setup and Usage Instructions

## 📋 Project Overview
This project implements machine learning models to predict campus placement outcomes based on student academic and personal data. The project includes four different algorithms: Logistic Regression, Decision Tree, Gradient Boosting, and K-Nearest Neighbors.

## 🚀 Quick Start Guide

### Prerequisites
- Python 3.8 or higher
- pip (Python package installer)
- Git (for cloning the repository)

### Step 1: Environment Setup

#### Option A: Using Virtual Environment (Recommended)
```bash
# Create a virtual environment
python -m venv campus_placement_env

# Activate the virtual environment
# On Windows:
campus_placement_env\Scripts\activate
# On macOS/Linux:
source campus_placement_env/bin/activate

# Install dependencies
pip install -r requirements.txt
```

#### Option B: Using Conda
```bash
# Create a conda environment
conda create -n campus_placement python=3.9

# Activate the environment
conda activate campus_placement

# Install dependencies
pip install -r requirements.txt
```

### Step 2: Data Preparation
1. Ensure you have the `Placement.csv` dataset in your project directory
2. The dataset should contain the following columns:
   - sl_no: Serial number
   - gender: Gender (Male/Female)
   - ssc_p: Secondary Education percentage
   - ssc_b: Secondary Education board
   - hsc_p: Higher Secondary Education percentage
   - hsc_b: Higher Secondary Education board
   - hsc_s: Higher Secondary Education specialization
   - degree_p: Undergraduate percentage
   - degree_t: Undergraduate type
   - workex: Work experience (Yes/No)
   - etest_p: Employability test percentage
   - specialisation: MBA specialization
   - mba_p: MBA percentage
   - status: Placement status (Placed/Not Placed)
   - salary: Salary (if placed)

### Step 3: Running the Models

#### Option A: Using Jupyter Notebook
```bash
# Start Jupyter Notebook
jupyter notebook

# Open your browser and navigate to the notebook files:
# - Logistic Regression.ipynb
# - Decision Tree.ipynb
# - Gradient Boosting.ipynb
# - K-Nearest Neighbor.ipynb
```

#### Option B: Using Jupyter Lab
```bash
# Start Jupyter Lab
jupyter lab
```

### Step 4: Model Execution Order
1. **Logistic Regression.ipynb** - Start with this for baseline performance
2. **Decision Tree.ipynb** - Understand feature importance
3. **Gradient Boosting.ipynb** - Advanced ensemble method
4. **K-Nearest Neighbor.ipynb** - Non-parametric approach

## 📊 Understanding the Models

### Logistic Regression
- **Best for**: Baseline comparison and interpretability
- **Key Features**: Linear decision boundary, probability outputs
- **Use Case**: When you need to understand feature importance

### Decision Tree
- **Best for**: Feature importance analysis
- **Key Features**: Non-linear relationships, interpretable rules
- **Use Case**: Understanding decision paths and feature splits

### Gradient Boosting
- **Best for**: High accuracy predictions
- **Key Features**: Ensemble method, handles overfitting
- **Use Case**: Production-ready predictions

### K-Nearest Neighbors
- **Best for**: Non-parametric classification
- **Key Features**: Instance-based learning, no training required
- **Use Case**: When data distribution is unknown

## 🔧 Customization Options

- **Logistic Regression**: C parameter tuning

## 🛠️ Troubleshooting

### Common Issues and Solutions

#### Issue 1: Import Errors
```bash
# Solution: Reinstall packages
pip install --upgrade pandas numpy scikit-learn
```

#### Issue 2: Jupyter Not Starting
```bash
# Solution: Install ipykernel
pip install ipykernel
python -m ipykernel install --user
```

#### Issue 3: Memory Issues with Large Datasets
- Reduce dataset size for testing
- Use data sampling techniques
- Increase system memory allocation

#### Issue 4: Model Performance Issues
- Check data quality and missing values
- Verify feature encoding
- Adjust hyperparameters
- Consider feature scaling
